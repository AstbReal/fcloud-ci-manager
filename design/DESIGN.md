# fcloud-ci-manager · UI 设计规范 v1

> 配套可交互原型：`design/ui-prototype.html`（直接双击打开，或访问 `#board` / `#module` 直达某一屏）
> 上位文档：`fcloud-ci-manager-spec.md` §10。本文件只补充与细化，不推翻已定决策；与 spec 冲突处以本文件末尾「与 spec 的差异」说明为准。

---

## 0. 设计立场

这是**运维每天要盯的工具**，不是营销页。三条原则按优先级排序：

1. **信息密度优先于留白。** 一屏看得完 12 个变量 × 4 个环境，比"呼吸感"重要。
2. **状态必须可分辨。** 值 / 继承 / 未配置 / 加密，四种状态在 0.5 秒内必须能区分，且不依赖颜色单通道。
3. **危险操作要慢，日常操作要快。** 删应用、恢复备份走二次确认；改一个变量值必须一键到位（点开即编辑，Enter 存）。

视觉基调：**中性灰底 + 单一蓝色强调 + 环境色语义化**。不引入第二种强调色，不用渐变、玻璃、投影堆叠。

## 1. 设计令牌

### 1.1 颜色

| 令牌 | 值 | 用途 | 对比度（白底） |
| --- | --- | --- | --- |
| `--bg` | `#f5f6f8` | 页面底色 | — |
| `--surface` | `#ffffff` | 卡片 / 表格 | — |
| `--surface-2` | `#fafbfc` | 表头、卡片次级底 | — |
| `--surface-3` | `#f2f4f7` | hover、chip、tag 底 | — |
| `--border` | `#e6e8ed` | 常规分隔线 | — |
| `--border-2` | `#d7dbe3` | 输入框 / 按钮描边 | — |
| `--text` | `#101828` | 主文本、变量值 | 17.8:1 |
| `--text-2` | `#5a6472` | 次要文本、表头 | 6.0:1 |
| `--text-3` | `#6b7584` | 辅助说明、时间戳 | 4.7:1 |
| `--primary` | `#2563eb` | 主操作、选中态、覆盖标记 | 5.1:1 |
| `--danger` | `#dc2626` | 删除、高危、必填星号 | 4.9:1 |
| `--warn` | `#b45309` | 待同步、即将到期 | 5.0:1 |
| `--ok` | `#047857` | 有效、已同步 | 4.9:1 |

环境语义色（仅用于圆点与列头，不铺满单元格）：

```
dev #0284c7 · test #7c3aed · staging #d97706 · prod #dc2626
```

> 环境色只做**辅助识别**：列头同时有文字标签，prod 额外带 `默认` 徽标。色盲用户可正常使用。

**禁用**：紫色/青色等额外强调色；纯黑 `#000`；低于 4.5:1 的灰色正文。

### 1.2 字体

```css
--sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
        "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--mono: ui-monospace, SFMono-Regular, "JetBrains Mono", Menlo, Consolas, monospace;
```

单镜像内网部署，**不引入 webfont**（零外部请求、无 FOUT）。若将来允许，首选 `Inter + JetBrains Mono`；次选 `IBM Plex Sans + IBM Plex Mono`。

字号阶梯（基准 14）：

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 20 | 650 |
| 卡片标题 / 弹窗标题 | 14–15 | 600 |
| 正文 / 表格 | 13–14 | 400 |
| 表头 / 元信息 | 11.5–12.5 | 600 / 400 |
| 变量 key、值、code | 12.5（mono） | 500 |

数字统一 `font-variant-numeric: tabular-nums`。

### 1.3 间距 / 圆角 / 阴影

- 间距阶梯：**4 / 8 / 12 / 16 / 20 / 24 / 32**。页面内边距 24；卡片内边距 16；卡片间距 16。
- 圆角：容器（卡片、抽屉、弹窗）**8px**；控件（按钮、输入、chip、单元格）**6px**；头像/圆点全圆。
- 阴影：
  - 静置 `0 1px 2px rgba(16,24,40,.05)` —— 只为了让白卡在灰底上有边界，几乎看不见。
  - 浮起（抽屉/拖拽 ghost）`0 14px 32px -10px rgba(16,24,40,.18)`。
- **不要**给每个卡片加 hover 位移或放大。只有可点击的卡片（应用卡片）允许 hover 变边框色。

### 1.4 骨架

```
侧栏 220px（白底，右侧 1px 描边）
  ├ 品牌区 56px
  ├ 分组导航（配置 / 系统 / 帮助）
  └ 底部状态条（版本 + PG/Redis 健康）
主区
  ├ 顶栏 56px（面包屑 + 环境 pill + 用户区）
  └ 内容区 padding 22/26，最大不设宽（工具类产品充分利用横向）
```

导航项 36px 高、6px 圆角、左侧 3px 主色条 + `--primary-50` 底色表示选中。分组标题 11px、字距 .07em、`--text-3`。

## 2. 组件规范

### 2.1 按钮

| 类型 | 用法 | 样式 |
| --- | --- | --- |
| Primary | 一屏仅一个 | `#2563eb` 实底白字，32px 高 |
| Default | 常规次级操作 | 白底 + `--border-2` 描边 |
| Ghost | 卡片头部的"查看全部" | 透明底，hover 出现 `--surface-3` |
| Danger | 吊销 / 删除 | 白底红字红边，hover 红底 50% |

高度：默认 32，紧凑 28。图标 15px，与文字间距 6px。**按钮内不放 emoji。**

### 2.2 标签

| 类型 | 场景 | 示例 |
| --- | --- | --- |
| `tag-plain` | 中性状态 | 明文、定时、操作员 |
| `tag-lock` | 加密变量 | 🔒 加密 |
| `tag-shared` | 共享模块、管理员 | 共享、模块管理员 |
| `tag-ok` / `tag-warn` / `tag-danger` | 有效性阶梯 | 有效 / 5 天后到期 / 已吊销 |

高度 20px，字号 11.5，圆角 5px。**标签不做按钮用**，可点击的标签（如抽屉里"保留为自有"）需加描边区分。

### 2.3 表格

- 行高 44，单元格内边距 12，表头 36（`--surface-2` 底、11.5px、600）。
- 行分隔线 `#f0f1f5`，**不加斑马纹**，hover 行 `#fbfcfe`。
- 首列可 sticky（矩阵场景），需 `.sticky{background:var(--surface)}` 且 hover 时同步变色。
- 空值显示 `—`（`--text-3`），不显示 "null"。

### 2.4 变量矩阵单元格（核心组件）

一行 4 种状态，**形状 + 颜色双重编码**：

| 状态 | 视觉 | 语义 |
| --- | --- | --- |
| 已配置（全局值） | 白底 + `1px #eceef3` 描边 + mono 值 | 该作用域有值 |
| 环境覆盖 | 同上 **+ 左侧 2px 主色条** | 本环境独立值，不跟随父环境 |
| 继承 | 无描边，灰字 `↳ 继承`，hover 提示来源环境 | 沿父链取值 |
| 未配置 | **1px 虚线** + `未配置` | 该列无值且无可继承 |
| 加密 | 灰底 + `••••••`（字距 .16em）+ 右侧眼睛 | 有值但需 reveal |

交互：

- 单击 → 原地变输入框（描边 `--primary` + 3px `rgba(37,99,235,.12)` 外环），Enter 保存，Esc 取消，失焦即保存。
- **编辑态不叠加浮动提示**：`Enter 保存 · Esc 取消` 曾放在单元格上方 18px，实际会压住 sticky 表头，删掉；快捷键写进帮助面板，不占界面。
- 清空输入并 Enter = 删除覆盖，回到继承态（不弹确认，走 toast 撤销）。
- 加密值只能"整格覆盖写入"，看不到旧值也不能比对。
- 行首拖拽柄默认 `opacity:0`，行 hover 才出现 —— 减少视觉噪音。

### 2.5 卡片

`1px solid var(--border)` + 8px 圆角 + 极弱阴影。卡片头 13px 内边距、标题 13.5/600、右侧放 ghost 按钮。卡片脚用于计数/容量等次要信息，12.5px、`--text-3`。

### 2.6 空态 / 加载 / 错误

- **空态**：线性图标 44px（`#d1d5db`）+ 一句说明 + 一个主按钮。说明里给"下一步做什么"，不写"暂无数据"。
- **加载**：骨架屏，块状灰条（`--surface-3`），**不用整页 spinner**；表格场景保留表头，只骨架化行。
- **错误**：页面内联错误条（红底 50%、红色描边、写明原因 + 重试按钮），不用全屏遮罩。

### 2.7 抽屉 / 弹窗

- 编辑一律走右侧抽屉（宽 480 / 640），头 16/20 内边距、底操作区右对齐。
- 弹窗只用于**危险确认**：删除应用需输入应用名，恢复 OVERWRITE 需输入 `OVERWRITE`。
- 遮罩 `rgba(16,24,40,.32)`，Esc 关闭，点击遮罩关闭（危险确认除外）。

## 3. 关键页面

### 3.1 工作台

四类待办 **2×2 栅格**，每卡最多 3 条 + "查看全部"：

1. 缺必填变量（红）
2. 模板待同步（琥珀）
3. Token 7 天内到期（蓝）
4. 24h 高危操作（红）

顶部一行 4 个统计卡（26px 大数字 + 小字单位 + 左侧 3px 语义色条），**只做摘要，不做图表**。下方"最近打开的模块"表格。

待办条目是一整行可点击区域：图标 26px 圆角方块 + 主标题（mono 模块名 + 环境标签）+ 一行原因 + hover 才出现的动作文字。

### 3.2 应用看板

```
┌ 左栏 264px ──────┬ 右栏：图例条 + 应用卡片墙（minmax 320px, 1fr）┐
│ 共享模块库（3）   │ ● 缺必填  ● 模板待同步  无标记=正常   检查于 2 分钟前│
│ 模板库入口        │ [ 应用卡片 ] [ 应用卡片 ]                    │
└──────────────────┴──────────────────────────────────────────────┘
```

- 应用卡片：30px 字母方块 + 名称 + **风险徽标**（`2 处问题` / `1 待同步`，无问题时完全不出现）+ mono code + `⋯` 菜单 / 描述 / 按 `groupName` 分组的模块 chip / 订阅组（虚线 chip + `+ 订阅`）/ 卡片脚计数。
- 卡片等高：`.appcard` 是 flex 列，卡片脚 `margin-top:auto`，同排底边对齐。
- 断点：`>980px` 保持左栏 + 卡片墙；`≤980px` 左栏落到上方。卡片 `minmax(320px,1fr)`，1280 下 2 列、1440 下 2 列（单卡约 430px，chip 不折行）。

**健康度徽标：用 chip 左侧的状态点，不新增装饰色**

| 状态 | 视觉 | 含义 |
| --- | --- | --- |
| 缺必填变量 | 红点（6px + 3px 淡红环） | 该模块在此应用下至少一个环境缺必填项 |
| 模板待同步 | 琥珀点 | 关联模板有新增/变更未同步 |
| 正常 | **不显示点** | 不画"健康绿点"：一屏 30 个绿点等于没有信息 |
| 共享模块 | 虚线边框 + `chip-sub` | 归属性质，与健康度正交，不抢颜色 |

- 组别信息由 `基础 / 业务 / 订阅` 的文字标题承担，**不再用彩色点表示分组**——同一个 6px 圆点不能既表示分组又表示健康。
- 卡片级徽标取该卡内最严重的状态：有红显示 `n 处问题`，否则有琥珀显示 `n 待同步`，都没有则不渲染（`.risk` 默认 `display:none`）。

**订阅共享模块：一次点击，不做拖拽**

```
应用卡片「订阅」组
  └ [＋ 订阅] → 弹层：搜索框 + 共享模块列表（复选框 + 订阅数 + 一行描述 + 已订阅标签）
                              勾选即生效，可随时取消
```

- 入口放在**结果所在的地方**（订阅组末尾），而不是卡片头部再加一个按钮：0 订阅时只剩这个虚线 chip，天然成为空态提示。
- 弹层常驻不关闭，支持连续勾选多个；勾选后卡片 chip、卡片脚 `n 订阅`、左栏 `n 订阅`、风险徽标同步刷新。
- 反向入口：点左栏共享模块名 → 右侧抽屉「订阅应用」，4 个应用逐个勾选，与卡片侧写同一份状态。
- 为什么不拖拽：源在左栏、目标在右侧滚动卡片墙，两者不同屏；订阅结果是"关系"不是"位置"；低频操作不配专属手势；跨卡片拖模块 chip 是**复制**而非移动，手势语义会骗人。

### 3.3 模块详情

- 头部：标题 + mono 路径（`app / module`）+ 一行元信息（变量数 · 环境数 · 最后更新）；右侧 `粘贴导入 / 复制 dotenv / 复制深链 / + 变量`。
- 模板更新条：琥珀色横条，一句话说清"新增 x / 变更 y / 删除 z"，右侧"查看并同步"打开抽屉。

**① 矩阵工具栏（常驻在矩阵之上）**

```
[🔍 搜变量、值、备注        /]  (全部 12) (DB_* 7) (REDIS_* 3) (APP_* 2) (未配置 2) (有环境覆盖 7)      显示 12 / 12
```

- 搜索匹配**变量名 + 明文值 + 备注**；密文值不建索引（搜不到密码，这是安全属性不是缺陷）。
- 前缀胶囊由命名空间自动聚合，数字实时算；单选，再点一次回到"全部"。
- **不做"分组折叠"**：折叠会藏掉行，而这里的目标是"找出要看的那几行"。前缀胶囊就是折叠——按命名空间收窄，零额外学习成本。
- 行数少时工具栏也在：它是这个页面的主入口，不该随数据量出现/消失。
- 无命中：表内空态（一句解释 + 两步操作），不用 toast。

**② 继承链 popover（只在这一处画链）**

点任意 `↳ 继承` 单元格，在它下方（放不下则翻到上方）弹出 332px 卡片：

```
REDIS_HOST  [test]                    继承链
● test     [当前格]                     未定义
● dev      [命中]                    127.0.0.1
● 全局值                              10.0.1.9
更具体环境优先                        [ 在 test 覆盖 ]
```

- 顺序：本层 → 更通用层（dev 最通用）→ 全局值，最多 5 行。
- 命中行：`--primary-50` 底 + 左侧 2px 色条 + `命中` 标签 + 值加粗主色；未定义行灰度显示 `未定义`；显式清空显示 `已清空（阻断继承）`。
- 底部「在 {env} 覆盖」= 把这格就地变编辑态，不用先关弹层再点一次。
- 为什么只有这一处该用树：层级 ≤ 5、范围被一个单元格限定、回答的是"这个值从哪来"。**应用 → 模块 → 环境 → 变量** 那种全局关系谱不做（纯包含关系，节点数爆炸，横向排布截断值）。

**③ 深链**

`/modules/{id}?env=prod&var=DB_HOST`

- 入口：页面头部「复制深链」、单元格 `⋯` →「复制此值链接」。复制到剪贴板并 toast 回显。
- 打开后的行为链：切到模块页 → 清空当前筛选 → 行加浅蓝底 + 单元格加 2px 主色环 → 顶部出现「已从链接定位到 `DB_HOST · prod`」条（带"清除定位"）→ toast 确认。
- 目标行若被筛掉，先清筛选再定位——**链接优先级高于用户上次的筛选状态**。
- 原型内等价写法：`#module?var=DB_HOST&env=prod`。

- 矩阵满宽，`table-layout:fixed` + `min-width:1072px`，最大高度 `calc(100vh - 326px)`，表头与首列 sticky。
- 列宽：拖动 28 / 变量 198 / 类型 62 / 备注 128 / 全局值 154 / 每个环境 118 / 操作 30。**1440 与 1366 下四环境同屏不挤压**，1280 以下横向滚动而不是 wrap。
- 矩阵下方 320px + 1fr 两栏：文件（含容量占用）/ 成员。

## 4. 交互与可访问性

- **键盘**：所有可点元素可 Tab 到达；焦点环统一 `outline: 2px solid rgba(37,99,235,.45); outline-offset: 1px`，**不写 `outline:none`**。
- **矩阵键盘路径**：Tab 依次进入单元格 → Enter 进入编辑 → Esc 退出。
- **`/` 聚焦矩阵搜索**：仅在模块页生效，输入框内不劫持；Esc 清空并退出。
- **拖拽只留给排序**：矩阵变量行排序（结果=位置、源与目标同屏、可撤销）保留拖拽；订阅/复制/授权/建关系一律用选择器、菜单或表单。
- **弹层规则**：`Esc` 关闭、点外部关闭、打开时焦点进第一个输入框；继承链 popover 与订阅选择器共用同一套行为，不各自发明。
- **不用颜色单独编码**：必填用 `*`、覆盖用左侧色条、未配置用虚线、高危用标签文字。
- 复选框/开关命中区不小于 28×28（视觉 15px，padding 撑开）。
- 文案：动作用动词（"签发 Token"），状态用名词（"已吊销"）；错误文案说**怎么办**而不是"操作失败"。

### 5.1 变量覆盖

```css
:root{
  --el-color-primary:#2563eb;
  --el-color-success:#047857;

  --el-color-info:#6b7584;
  --el-border-radius-base:8px;      /* 容器 */
  --el-border-radius-small:6px;     /* 控件 */
  --el-text-color-primary:#101828;
  --el-text-color-regular:#5a6472;
  --el-text-color-secondary:#6b7584;
  --el-border-color:#e6e8ed;
  --el-border-color-light:#e6e8ed;
  --el-fill-color-light:#f2f4f7;
  --el-bg-color-page:#f5f6f8;
```

按钮圆角如需 6px：`.el-button{border-radius:6px}`。

### 5.2 改动清单

| 文件 | 改什么 |
| --- | --- |
| `frontend/src/styles/main.css` | 全量替换为令牌 + 基础层（见原型 `<style>` 上半部分） |

### 5.3 实现中确认的三条硬约束

**① 雪花 ID 必须以字符串下发。**
19 位 ID 超过 `Number.MAX_SAFE_INTEGER`，以 JSON 数字返回会在 `JSON.parse` 时被静默舍入
（`…950914` → `…951000`），表现为"列表能看、点进去 404"。后端 `JacksonConfig` 统一把
`Long` 序列化为字符串，前端 `Id` 类型只用做透传与相等比较，**不得参与算术**。

**② 变量矩阵永不回传明文。**
加密变量在矩阵里固定是 `••••••`；明文只能经 `POST /variables/{id}/reveal` 取，且该接口写
审计日志。"有权查看" 不等于 "默认展示"，否则审计形同虚设。

**③ 健康度只在后端算。**
`missingRequired` 是「变量 × 环境」对数，`templatePending` 是模板 `updated_at` 与模块
`template_synced_at` 的比较。前端只渲染结果，不自行推算——否则筛选、分页、订阅都会让数字漂移。
