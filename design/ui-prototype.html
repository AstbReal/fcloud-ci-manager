流水线接入

三个只读接口；变量值不会被写入任何服务端日志。
1 · 拉取变量（dotenv）
GET
bash# modules 必填，逗号分隔；按请求顺序输出 curl -sS \ -H "Authorization: Bearer $FCLOUD_TOKEN" \ "https://hub.example.com/api/v1/pipeline/config?application=payment-service&environment=prod&modules=db-config,common-notify" # 响应 text/plain，每个模块以 # module: {code} 开头
2 · 批量下载文件（tar.gz）
POST
bashcurl -sS -X POST \ -H "Authorization: Bearer $FCLOUD_TOKEN" \ -H "Content-Type: application/json" \ -d '{"environment":"prod","modules":["db-config"],"files":["schema.sql"]}' \ "https://hub.example.com/api/v1/pipeline/artifacts" -o artifacts.tar.gz
错误码
401Token 缺失 / 无效 / 过期 / 吊销
403模块不属于该应用
400modules 缺失，或模块未绑定该环境
404文件不存在
429超过 60 次 / 分钟
